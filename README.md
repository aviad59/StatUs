# StatUs

Monorepo for StatUs services, managed with [pnpm workspaces](https://pnpm.io/workspaces).

| Path | Description |
| --- | --- |
| `services/frontend` | React + Vite + TypeScript + Tailwind web app |
| `packages/` | Shared libraries |

## Getting started

```sh
corepack enable   # once, as admin; or: npm i -g pnpm
pnpm install
pnpm dev
```
