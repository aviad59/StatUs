# Story images (to pre-generate)

List the photos characters can use for their stories. Later these get generated once,
ahead of time, and a character picks one that fits when they post a story, instead of
drawing a new image every time.

One line per image, under the character it belongs to:

    - what the photo shows | when to use it (optional)

Write in Hebrew or English, whichever is easier. Keep "what it shows" concrete (a place,
an object, the light). People appear only from behind or as hands, since faces aren't
consistent between images. Don't put the story's text in the photo: the text is written
on top of it later.

The first line in each section is an example; replace it or keep it.
